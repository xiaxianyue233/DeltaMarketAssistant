# 测试和复现

## 仓库内可移植测试

```powershell
.\tools\Build.ps1
```

使用 .NET 8 在 Windows 上构建后运行测试控制台。当前包含 20 项默认检查和 1 项局部倒计时样本检查，共 21 项。测试使用临时目录保存/加载配置，不操作真实游戏或发送购买输入。

覆盖坐标换算、稳定帧、点击节奏、普通冲刺和两秒补购窗口、返回/成功保护、配置迁移和保存、时间输入与组合键解析等。本地样本位于 `countdown-samples`，可在新机器或 GitHub Actions 复现。

## 扩展截图测试

开发阶段的 30 项结果包括另外 9 项个人截图/校准扩展测试。完整游戏截图、个人配置以及包含账号信息的 UI 截图未上传，所以新克隆仓库的默认测试不是 30 项。

扩展入口按下列顺序接收本地文件：

```powershell
dotnet run --project .\tests\DeltaMarketAssistant.Tests\DeltaMarketAssistant.Tests.csproj -c Release -- `
  --countdown-samples .\countdown-samples `
  --fixtures <一级商城> <原二层> <实际挂牌二层> <个人配置JSON> <返回一级或空收藏> `
  --results <队列已满> <roll失败> `
  --success <获得外观与跳过页面> `
  --listing <无可信倒计时但有绿色按钮的挂牌页面>
```

以上尖括号是参数占位说明，实际使用时替换为本机图片/配置路径并按需加引号。测试只读取这些文件。可分别以有商品和空收藏的一级截图运行，验证两类返回。

## UI 测试与真实流程

测试程序另有 `--ui <编译后的应用DLL> <截图输出目录>`，用于独立的布局和控件测试，需交互式桌面，不作为 GitHub Actions 默认检查。普通编译和单元回归不启动 UI 测试。

真实游戏验收应先使用仅识别模式核对校准与日志，再验证一轮输入、返回和刷新。自动测试无法替代真实环境的前台遮挡、渲染延迟和输入接收检查；当前源码归档操作不自动进行真实购买。
